# GRIX Bangladesh 🇧🇩

![GRIX Logo](assets/grix-logo2.jpg)

**GRIX** is a premium unisex clothing brand based in Dhaka, Bangladesh. We offer quality fabrication, full customization, and delivery to all 64 districts. 

> *"We offer you what you deserve."*

## 🚀 Live Website
Visit the live site here: **[https://grixbd.github.io/explore-on/](https://grixbd.github.io/explore-on/)**

## ✨ Features
- **Modern UI/UX:** Smooth preloader, custom cursors, and elegant slide-out menus.
- **Fully Responsive:** Optimized for mobile, tablet, and desktop devices.
- **SEO Ready:** Includes Open Graph (OG) tags, Twitter cards, and a `sitemap.xml`.
- **Accessible:** Built with ARIA labels, focus trapping, and `prefers-reduced-motion` support.
- **Interactive Elements:** Accordion FAQ, dynamic stat counters, and clipboard integration for email copying.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3** (Custom properties, Flexbox, CSS Grid, Keyframe animations)
- **Vanilla JavaScript** (DOM manipulation, Intersection Observer, History API)
- **Fonts:** Playfair Display, Inter, Space Grotesk
- **Icons:** FontAwesome 6
